Remote

Connect your app across devices.

Remote gives desktop applications a shared way to pair devices, authorize sessions and deliver their existing features to browser, desktop and mobile clients.

One connection model, your application

Pair once

A short-lived pairing address grants a device access to the capabilities your application explicitly registers. Revoke that device through the same host lifecycle.

Keep existing contracts

Deliver API requests, events and content without replacing your product models. Streaming transports preserve cancellation and media requests.

Choose each runtime

Compose browser, Angular, Node, Electron and Capacitor adapters around the same protocol. Your application supplies storage, authorization and certificates.

Add the parts your app needs

Protocol and session packages stay independent of UI frameworks. Runtime adapters own their network and operating-system boundaries. 

remote-protocol → remote-core
remote-protocol → remote-client

remote-node       remote-browser
remote-electron   remote-capacitor
remote-angular   remote-testing

Start with a local connection

The LAN transport connects directly to the host. HTTP is an explicit unencrypted mode; HTTPS uses certificate material supplied by your application. No SDK domain or hosted account is required. 

git clone https://github.com/pixel-brewery/remote.git
cd remote
corepack enable
yarn install --immutable
yarn verify
