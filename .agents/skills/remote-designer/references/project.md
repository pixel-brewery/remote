# Remote design contract

The product demo will use the applicable Mosaik components and the adopted theme documented with that demo. Host applications own their own theme and UI. Consult the local versioned catalog before choosing visual patterns, components, interactions or tokens.

Use the repository's `mosaik` connection, which runs the pinned `@pixel-brewery/mosaik-mcp` package through `yarn exec mosaik-mcp`. Compare catalog APIs against the consumer's actual installed components. Validate the source and inspect the rendered flow at relevant widths, keyboard paths and motion settings before delivery.

Repository artwork is an original brand illustration. Its sources and provenance live under `.github/assets/`.

Remote uses the approved interlocking-link mark and indigo primary `#5B4BDB`. Petrol is reserved for Cursor. Preserve the reference portfolio composition, with Remote-owned artwork and truthful capability copy.
