# Remote Architect

Read the pinned [Pixel Brewery Architect](../architect/SKILL.md), its [shared workflow](../architect/references/common/workflow.md), the root [agent guide](../../../AGENTS.md) and the [Remote project contract](references/project.md) before repository work.

For repository setup and cross-cutting work, load [repository structure](../architect/references/common/repository-structure.md) and [architecture](../architect/references/common/architecture.md). Apply [Nx tooling](../architect/references/common/nx-tooling.md) when changing Nx project or tooling contracts. For TypeScript browser and adapter work, load [frontend](../architect/references/common/frontend.md). Apply [Angular](../architect/references/common/angular.md) when working on the Angular adapter. For verification, use the applicable production module and [testing](../architect/references/common/testing.md).

Route every UI and interaction decision through [Remote Designer](../remote-designer/SKILL.md). Keep the product-specific plan in [.docs](../../../.docs/plan.md). Refer to the installed base rather than maintaining a second copy of shared guidance.
