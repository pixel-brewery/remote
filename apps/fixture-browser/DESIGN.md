# Acceptance fixture foundations

The shared packaged fixture uses Soho, Inter and the theme's radius, stroke and spacing. It supports light and dark modes. Remote's indigo primary `#5B4BDB` comes from the owner's approved brand and is supplied through `ThemeGenerator.generatePalette`, with no component token overrides.

The versioned local `@pixel-brewery/mosaik-mcp@0.1.205` catalog was consulted for authoring rules, templates, recipes, component APIs, native integration and theme tokens. The complete tool evidence is in [catalog-evidence.json](design/catalog-evidence.json). `recipe-profile-settings` provides the bounded form grouping; its deprecated Stack and custom painted wrappers were adapted to CSS layout and actual Card primitives according to the current component contracts. No connection-specific template was returned.

TextBox owns invitation/device/note entry, Button owns all actions, Card/Header/Title/Content own grouping, Message owns actionable failure/lifecycle feedback and Text owns labels. The sole plain text area is technical streamed evidence in a semantic `pre`. CSS arranges spacing, wrapping and scrolling. Installed components and catalog both use 0.1.205. The runtime uses documented public custom-element properties and native composed click actions (the installed Button template and event API supersede the framework guide's stale click-event example).

The Nx theme owner generates `src/theme/fixtureTheme.json` from the published Soho definition and both Indigo palettes. `src/registerFixtureElements.js` registers the public runtime components, and `src/theme/initializeFixtureTheme.js` applies the generated data through Theme2/ThemeService, including reapplying the active scheme after mode changes. Application, connection and Playwright contracts remain strict TypeScript. This regular runtime boundary avoids consuming the invalid published0.1.205 declaration graph documented in [Mosaik issue1397](https://github.com/RueDeRennes/mosaik/issues/1397); it does not fix that upstream defect or replace component types.
